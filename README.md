                                                    Language-Detection-Project
Project Overview  The goal of this project is to build a model that can automatically detect the language of a given input sentence using Natural Language Processing (NLP) techniques.  The dataset contains labeled text samples in multiple languages, and a machine learning model is trained on this data to predict the language of new input text.

Dataset

The dataset consists of two columns:

text: The input sentence
language: The corresponding language label

Features

Multi-language text classification
Preprocessed text data
Machine Learning model training
Model evaluation and prediction
Supports multiple languages:
English
Urdu
Spanish
French
German


Techniques Used
Text Preprocessing (lowercasing, cleaning)
Tokenization
Feature Extraction (e.g., TF-IDF / Count Vectorizer)
Machine Learning Algorithms (e.g., Naive Bayes, Logistic Regression)
Model evaluation metrics (accuracy, precision, recall)

Libraries Used
Python
pandas
scikit-learn
numpy
joblib (for model saving/loading)
